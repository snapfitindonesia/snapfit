# Arsip — dokumen perencanaan (sebelum launch)

Dokumen di folder ini ditulis **sebelum** situs dibangun, sebagai rencana & panduan
belajar. Banyak yang sudah tidak sesuai kondisi sekarang, misalnya:

- CDN foto kini **Cloudflare R2** (`cdn.snapfit.id`), bukan hosting cPanel via FTP.
- DNS kini di **Cloudflare**, bukan cPanel aRenHost.
- Tracking langsung **gtag + Meta Pixel + CAPI**, tanpa GTM.
- Deploy lewat **Vercel CLI**, bukan auto-deploy GitHub.
- Pembayaran default **transfer manual BCA** dan ongkir **flat** (Midtrans/Biteship menunggu verifikasi).

Simpan hanya sebagai sejarah keputusan. Dokumentasi yang berlaku ada di [`../README.md`](../README.md).
